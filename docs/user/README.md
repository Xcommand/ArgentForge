# Argent Forge, from zero

A guide for someone who has never opened SLADE and doesn't want to read the source to find out
where things are. It assumes you know what a mod for a Doom engine game is, and nothing about making
one.

* [Basics](basics.md): what the program edits, what you see when it opens, how a file gets from the
  tree into an editor and back onto disk.
* [Making an actor](actor.md): DECORATE and ZScript mostly without typing them, and what the
  constructor won't touch.
* [Drawing pictures](image-editor.md): the brush, the mouse gestures, and a texture that tiles without
  a seam.

The program's own start page has a shorter version of the same news under **What's Different Here**.
[CHANGES.md](../../CHANGES.md) is the full list of what this fork does differently from SLADE3.
